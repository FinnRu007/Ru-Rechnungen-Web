Auf die Speicherdauer der Logfiles bei GitHub habe ich keinen Einfluss. Einzelheiten: GitHub Privacy Statement.

Der Download des Windows-Programms wird ebenfalls über GitHub bereitgestellt (Release-Seite des Projekts). Beim Download gelten dieselben Angaben.

Das Werkzeug unter E-Rechnung lesen verarbeitet die von Ihnen ausgewählte Datei ausschließlich lokal in Ihrem Browser.
